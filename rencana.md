# Catatan Rencana Website
Website SMP Islam Plus Al-Imam Kediri

## Tujuan
Menampilkan profil, kegiatan, fasilitas, dan prestasi sekolah
secara informatif dan menarik.

## Teknologi
Hanya HTML, CSS, dan JavaScript native (tanpa framework/library).

## Section / Halaman
1. Beranda (sambutan singkat sekolah)
2. Profil sekolah (visi dan misi)
3. Kegiatan
4. Fasilitas
5. Prestasi
6. Kontak dan lokasi

## Tampilan
- Warna: biru tua (utama, sesuai logo sekolah), kuning emas (aksen/tombol), putih (latar), merah sedikit saja untuk penekanan
- Gaya: bersih, rapi, nyaman dibaca
- Bisa dibuka dengan baik di HP dan laptop

## Rencana tambahan (jika sempat)
- Animasi halus dan efek hover
- Gambar hasil AI yang relevan
- Favicon

## Pembaruan Rencana (20 Oktober 2026)
- Warna dipastikan: biru tua (utama), kuning emas (aksen/tombol), putih (latar), sesuai logo sekolah.
- Section yang dibuat: Beranda, Profil (sejarah, visi, misi, tujuan, NPSN dan status sekolah), Kegiatan, Fasilitas, Prestasi, Kontak dan Lokasi.
- Data diambil dari situs resmi sekolah dan Data Referensi Kemendikdasmen. Nama murid tidak dicantumkan demi privasi.
- Fitur yang ditambahkan: mode gelap dan terang (pilihan tersimpan), menu hamburger di HP, tampilan responsif untuk HP, tablet, dan laptop.
- Peta Google Maps tertanam diganti dengan tombol "Buka di Google Maps" supaya tetap murni HTML, CSS, dan JavaScript native.
- Website di-deploy melalui GitHub Pages: https://rana2012-crypto.github.io/web1/
